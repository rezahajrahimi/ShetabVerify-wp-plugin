INSTALLATION
EN: Upload the plugin files to the `/wp-content/plugins/webdide-card-to-card-verification` directory, or install via Plugins → Add New.
FA: فایل‌های افزونه را در مسیر `/wp-content/plugins/webdide-card-to-card-verification` آپلود کنید، یا از افزونه‌ها ← افزودن نصب کنید.

EN: Activate the plugin through the Plugins screen.
FA: افزونه را از صفحه افزونه‌ها فعال کنید.

EN: Go to WooCommerce → Settings → Payments and enable Card to Card for WooCommerce – WebDide Shetab.
FA: به ووکامرس ← تنظیمات ← پرداخت‌ها بروید و «کارت به کارت ووکامرس – WebDide Shetab» را فعال کنید.

EN: Open Shetab Management to configure the API secret, destination cards, and optional Telegram/Bale bots.
FA: از منوی مدیریت شتاب، کلید API، کارت‌های مقصد و در صورت نیاز ربات‌های تلگرام/بله را تنظیم کنید.

EN: Download the companion Android app from Cafe Bazaar.
FA: اپلیکیشن اندروید همراه را از کافه‌بازار دانلود کنید.

FAQ
EN: Do I need a specific bank account?
FA: آیا به حساب بانکی خاصی نیاز دارم؟

EN: No. It works with Iranian accounts that provide SMS or app notifications supported by the companion app.
FA: خیر. با حساب‌های ایرانی که اعلان پیامکی یا اپلیکیشنی مورد پشتیبانی اپ همراه دارند کار می‌کند.

EN: Does it support کارت به کارت / card-to-card?
FA: آیا از کارت به کارت پشتیبانی می‌کند؟

EN: Yes. The gateway is built for Iranian card-to-card (کارت به کارت) transfers with unique amount matching.
FA: بله. این درگاه برای انتقال‌های کارت به کارت ایران با تطبیق مبلغ یکتا ساخته شده است.

EN: Is it secure?
FA: آیا امن است؟

EN: Communication with the mobile app uses a private API Secret. Card numbers are stored encrypted. Bot webhooks only accept actions from configured chat IDs with signed callback data.
FA: ارتباط با اپلیکیشن موبایل با کلید خصوصی API انجام می‌شود. شماره کارت‌ها رمزنگاری‌شده ذخیره می‌شوند. وب‌هوک ربات فقط اقدام‌های chat IDهای تنظیم‌شده با دادهٔ امضاشده را می‌پذیرد.

EN: What happens if the app is offline?
FA: اگر اپلیکیشن آفلاین باشد چه می‌شود؟

EN: Orders stay On Hold. Customers can upload a slip; you can confirm from WooCommerce or from Telegram/Bale.
FA: سفارش‌ها در وضعیت در انتظار می‌مانند. مشتری می‌تواند رسید آپلود کند؛ شما از ووکامرس یا تلگرام/بله تایید کنید.

EN: How do Telegram / Bale bots work?
FA: ربات‌های تلگرام / بله چگونه کار می‌کنند؟

EN: Enable a bot in Shetab Management, set the token and allowed chat IDs, then click Set webhook. When a receipt is uploaded, the bot sends the image with Approve / Reject. Reject asks for an optional note.
FA: در مدیریت شتاب یک ربات را فعال کنید، توکن و chat IDهای مجاز را تنظیم کنید، سپس تنظیم وب‌هوک را بزنید. با آپلود رسید، ربات تصویر را با تایید / رد می‌فرستد. رد می‌تواند یادداشت اختیاری داشته باشد.
