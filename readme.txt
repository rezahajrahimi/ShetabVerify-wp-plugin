ShetabVerify — A WooCommerce payment gateway that issues unique-suffix amounts for bank transfers and confirms via REST API.

== Installation ==
1. Upload the plugin files to the `/wp-content/plugins/ShetabVerify` directory.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to WooCommerce → Settings → Payments and enable 'ShetabVerify'.
